# Sistema de Detecção de Sonolência e EPIs com Visão Computacional

Projeto de iniciação científica adaptado como base para o TCC, focado na detecção de sonolência, uso de EPIs e comportamentos de risco em ambientes industriais e laboratoriais utilizando YOLOv8, MediaPipe, OpenCV e alarmes sonoros.

## 📌 Funcionalidades

- ✅ Detecção de sonolência (olhos fechados, bocejo)
- ✅ Detecção de uso de EPIs: capacete, óculos, colete, máscara, bota, protetor auricular e touca
- ✅ Verificação de posicionamento correto dos EPIs
- ✅ Alarmes diferenciados para cada tipo de risco (falta de EPI, uso incorreto ou sonolência)
- ✅ Identificação de comportamentos de risco: uso de celular e alimentação
- ✅ Exibição de diagnóstico visual com cores (verde/vermelho) na tela

## 🧠 Tecnologias Utilizadas

- YOLOv8 (Ultralytics)
- MediaPipe (FaceMesh e Pose)
- OpenCV
- Python 3.10+
- Pygame (para alarmes sonoros)
